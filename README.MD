# sample data project
## Overview
python project that generates csv file containing sample data about people name age and city
# features
generate smaple records using python
exports data to csv format
use git and github for version control
## How to Run
1. Clone  this repository.
2. Open a terminal in the project folder.
3. Run "python sample_data.py"
4. The program generates `sample_data.csv`.
## Project Structure

```text
sample-data-project/
├── sample_data.py
├── sample_data.csv
└── README.md
```
## Sample Data

The generated CSV contains the following columns:
- `name`
- `age`
- `city`
